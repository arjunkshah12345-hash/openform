# Visual component sources

Openform adapts the gradients.sh [free gradient engine](https://gradients.sh/docs), the [dithercn](https://dithercn.dev/) Bayer threshold map, the [Dither Kit](https://tripwire.sh/dither-kit) gradient canvas, and the [VibeUI](https://tryjasmine.dev/) keyboard key component. These files are MIT licensed. See the notices in [public/licenses](public/licenses).

The hero also uses an original glyph field inspired by [asciicn](https://asciicn.sumak.dev/). Openform renders the field locally through Canvas 2D.
