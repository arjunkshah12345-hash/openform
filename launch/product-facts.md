# Openform product facts

Openform is an independent, MIT-licensed conversational form builder. It is not affiliated with Typeform.

Implemented: seven question types (short text, long text, email, multiple choice, rating, number, yes/no); six themes; visual editor; preview; publish/unpublish; public form links; responses with immutable question snapshots; CSV export; duplicate/trash/restore; self-hosted SQLite + Express; Docker deployment.

GitHub Pages build: interactive browser-local demo. Forms and demo responses stay in browser localStorage. Shared demo links include the form definition; answers submitted by other people do not arrive in the owner's browser. Use the self-hosted app for centralized response collection.

Not implemented: managed cloud hosting, teams/login, billing, file uploads, integrations, automated migration from Typeform, conditional branching, guaranteed email delivery. Do not imply these exist.
