# Openform launch film

Editable, deterministic Remotion motion graphics for the Openform launch. The landscape master and native portrait adaptation are 30 seconds at 30fps. There is no voiceover: the story works muted, with a quiet original synthesized soundtrack for sound-on viewing.

## Reproduce

Use Node.js 22.13 or newer from this directory:

```sh
npm ci
npm run studio
npm run render
npm run render:portrait
npx remotion still src/index.ts OpenformSocial out/openform-social.png
npm run still
```

`remotion.config.ts` disables generated bundle caching to keep disk use low. Rendering uses JPEG frame intermediates and two browser workers. The CLI downloads its own rendering browser when needed. The Studio is a development preview; final video comes from frame-based rendering.

## Outputs

- `out/openform-launch.mp4`: 1920×1080 landscape, H.264 + AAC.
- `out/openform-launch-portrait.mp4`: 1080×1350 portrait, H.264 + AAC.
- `out/thumbnail.png`: landscape product/brand preview.
- `out/openform-social.png`: 1200×630 sharing card.
- `out/contact-sheet.jpg`: sampled landscape frames for review.

Render outputs are ignored by Git. Publish the completed media separately or attach it natively to the approved social post. This project never publishes or schedules social content.

## Story

0–4s: Forms should feel like a conversation.

4–8s: Meet Openform. A little more human.

8–14s: Build. Show the editor and theme changes.

14–19s: Ask. Select an answer and publish.

19–24s: Listen. Inspect a sample response and export CSV.

24–30s: Your questions. Your data. Your code. Open source, MIT licensed.

The interfaces are animated product demonstrations, not recorded customer data. The sample response is marked as a demonstration. GitHub Pages is a browser-local demo; centralized response collection belongs to the self-hosted application. Film copy does not imply that the static demo runs a backend.

## Edit

`src/root.tsx` contains the landscape scenes and social card. `src/portrait.tsx` contains a native portrait composition with readable, rearranged UI. Timing uses Remotion frames; nothing depends on CSS animation or wall-clock time.

Color palette: warm paper, forest green, sage, peach, lilac, and lime. The included typefaces are DM Sans and DM Serif Display, bundled locally under their SIL Open Font License notices in `public/fonts/`.

`public/soundtrack.wav` is original synthesized audio generated by `synthesize-audio.py`; no third-party recording or stock music is used. The generator, motion source, and original artwork are covered by the repository MIT license. Remotion and other dependencies retain their own licenses.
