OPENFORM / PRACTICAL GUIDES

An open-source Typeform alternative you can self-host

What Openform does, what it does not do, and when a self-hosted conversational form builder makes sense.

By the Openform project · Updated November 17, 2026

What is Openform?

Openform is an MIT-licensed form builder for people who want a conversational, one-question-at-a-time experience and control over their own source code and response storage. The self-hosted application runs on Node.js with an Express API and a SQLite database.

Who is it for?

Developers and small teams who can operate their own application, want to customize the form experience, and need straightforward surveys, customer feedback, registrations, or lead forms.

What can you build?

Choose short text, long text, email, multiple choice, rating, number, or yes/no questions. Reorder questions, choose one of six themes, preview the conversation, then publish a shareable link. The owner workspace lets you read individual submissions and export answers as CSV.

What does the demo save?

The GitHub Pages demo stores data in your browser. A shared demo link includes the form definition, but it does not send answers back to the owner. Use the self-hosted version for centralized response collection.

What are the tradeoffs?

This is a single-owner application. It does not include a managed cloud service, user accounts, conditional branching, file uploads, integrations, or automatic imports from Typeform. Public deployment needs HTTPS and authentication in front of administrative routes. The form-creation API is not intended for untrusted visitors.

Can I migrate from Typeform?

Recreate your questions in the builder, check required fields and choices, publish the self-hosted form, and replace the old link or embed on your website. Keep existing response exports separately: an automated importer is not included. Test a full submission before directing respondents to the new form.

How much does it cost?

The source code is available under the MIT license. You pay any infrastructure and operating costs for your own deployment. This project does not sell a managed hosting plan.
